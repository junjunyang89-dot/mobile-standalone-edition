# 项目结构说明

## 📁 前后端分离结构

项目已完全分离为两个独立项目：

```
/Volumes/MOVESPEED/qa_coding/
├── mobile-standalone-backend/      # 后端项目（独立）
│   ├── pom.xml                      # Maven 配置
│   ├── src/main/java/               # Java 源代码
│   │   └── com/mobile/standalone/
│   │       ├── BackendApplication.java
│   │       ├── config/              # 配置类
│   │       ├── controller/          # REST API 控制器
│   │       ├── service/             # 业务逻辑层
│   │       ├── mapper/              # MyBatis Mapper
│   │       └── entity/              # 实体类
│   └── src/main/resources/
│       ├── application.yml          # 应用配置（MySQL）
│       ├── mapper/                  # MyBatis XML
│       └── db/schema.sql            # 数据库脚本
│
└── mobile-standalone-edition/       # 前端项目（当前项目）
    ├── package.json                 # Node.js 配置
    ├── src/                         # Vue 前端代码
    │   ├── views/                   # 页面组件
    │   ├── stores/                  # Pinia 状态管理
    │   ├── api/                     # API 客户端
    │   └── ...
    ├── electron/                    # Electron 主进程
    │   ├── main/                    # 主进程代码
    │   ├── preload/                 # 预加载脚本
    │   └── services/                # 本地服务
    └── dist/                        # 构建产物
```

## 🚀 启动方式

### 后端（独立项目）

```bash
cd /Volumes/MOVESPEED/qa_coding/mobile-standalone-backend
mvn spring-boot:run
```

### 前端（当前项目）

```bash
cd /Volumes/MOVESPEED/qa_coding/mobile-standalone-edition
npm install
npm run dev          # 浏览器模式
npm run dev:electron # Electron 模式
```

## 🔗 通信方式

前端通过 HTTP RESTful API 与后端通信：

- **后端地址**: `http://127.0.0.1:3080/api`
- **通信协议**: HTTP/JSON
- **API 客户端**: `src/api/index.ts`

## ✅ 优势

1. **完全独立**: 前后端可以独立开发、部署
2. **技术栈分离**: 后端 Java，前端 JavaScript
3. **易于维护**: 代码结构清晰，职责分明
4. **灵活部署**: 可以分别部署到不同服务器
